# Nazu - Cybersecurity Services Website

This project is a frontend website built using ReactJS for the CSCI390 Web Programming course (Phase 2 project).

## Project Overview

Nazu is a cybersecurity company website made to showcase the company’s services and information in a modern and simple way. Users can browse different pages, learn more about the company, and contact the company through a form. I Made this project since i really love cyber and im currently working a soc analyst.

## Website Pages

* **Home Page**
  Contains the main hero section and some feature cards explaining the company highlights.

* **Services Page**
  Displays the cybersecurity services offered by the company.

* **About Page**
  Includes company information, goals, and some statistics.

* **Contact Page**
  Has a contact form where users can send a message. Form validation is included.

## Technologies Used

* ReactJS
* CSS

## Setup Instructions
* Open the project folder in Visual Studio Code.
* npm install 
* npm start
